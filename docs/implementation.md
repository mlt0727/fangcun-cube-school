# 方寸：魔方学习台

按已确认的方案直接实施，使用无运行依赖的 HTML、CSS、JavaScript，发布到 GitHub Pages。解法完全在本机浏览器计算，计算放入 Worker。

## 实施顺序

1. 几何贴纸模型与真实状态校验；验证转动逆操作、角块朝向、棱块朝向和置换奇偶。
2. 三阶逐层求解：底层十字、底层角块、中层棱块、顶层十字、顶棱归位、顶角归位、顶角朝向。使用保留前一阶段成果的初学者公式；生成后独立重放验算。
3. 六面涂色和 CSS 3D 转层动画。步骤记录原子转动、所属阶段、公式、中文观察与检查提示；支持暂停、回退、重播、调速及键盘。
4. 四阶中心、配棱、特殊情况处理和三阶教学复用。求解不依赖输入的打乱历史。
5. 随机状态回放测试、浏览器交互和移动端检查；提供静态构建和 Pages 工作流。

## 验收边界

- 人工涂色的有效状态能够求解；无效输入给出中文错误，不默默改色。
- 回退后状态与之前一致；快速点击、暂停或切换模式不能串入旧动画。
- 不把最短解包装成分层教学；每个阶段结束都检查实际不变量。
- 不引入账户、数据库、在线 AI 或服务端求解。
